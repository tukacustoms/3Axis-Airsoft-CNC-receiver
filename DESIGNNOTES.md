# Design Notes

## Key Considerations

* Always think about tool access (3-axis)
* Avoid deep narrow pockets
* Prefer consistent wall thickness
* Make more plain faces for an better design aesthetic

---

## Ideas

* Split Upper into 3 parts for easier machining
* Use M3/M4 fasteners only
* Make base Receiver then go with different approaches based on them

---

## Inspirations

* Skeletonized AR receivers
* Gundam and Mecha Based anime characters
* Industrial minimalism
